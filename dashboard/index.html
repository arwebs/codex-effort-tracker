Coverage & interpretation

Active time is each agent’s own effort. Parallel agents can exceed elapsed wall time. Measured idle, provisional trailing idle and gaps with unknown status stay separate. A dash means unavailable; zero means measured zero. Workspace changes and relationships are lifetime details, not period totals. CSV downloads include all captured history.
